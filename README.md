SQL & Excel Data Analysis Project

Overview:
An end-to-end data analytics project using SQL and Excel to clean, analyze, and visualize business data. The goal is to build KPIs, dashboards, and insights that can be added to a portfolio.

Key Steps:
Import raw data into SQL
Clean and transform data
Write SQL queries to calculate KPIs (revenue, orders, trends, category share, etc.)
Export results to Excel
Build interactive dashboards with pivot tables and charts
Summarize insights and recommendations

Tools & Skills:
SQL (queries, aggregation, data cleaning)
Excel (pivot tables, dashboards, visualizations)
Data storytelling & KPI definition

Example Metrics:
Total revenue and total orders
Average order value
Sales by category/product
Monthly/daily sales trends
Best and worst performers

Project Structure
/data         → Raw datasets  
/sql          → Queries and scripts  
/excel        → Dashboard file  
/docs         → Notes and screenshots  

Learning Outcomes:
Hands-on practice with SQL + Excel workflow
Experience in cleaning and analyzing real-world-style data
Building dashboards and presenting business insights
