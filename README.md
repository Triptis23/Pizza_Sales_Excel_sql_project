# 📊 SQL & Excel Data Analysis Project  



## 📌 Overview  
This project demonstrates an end-to-end data analytics workflow using **SQL** and **Excel**.  
It covers data cleaning, KPI calculation, and dashboard building to showcase business insights.  

## 🚀 Key Features  
- Import and clean raw data in SQL  
- Write SQL queries to calculate KPIs:
  - Total revenue & total orders  
  - Average order value  
  - Sales by category/product  
  - Monthly/daily sales trends  
- Export results to Excel for visualization  
- Build an interactive dashboard with slicers & charts  
- Provide insights & recommendations  

## 🛠 Tools & Skills  
- **SQL** → Queries, joins, aggregations, data cleaning  
- **Excel** → Pivot tables, charts, dashboards  
- **Analytics** → KPI definition, trend analysis, data storytelling
